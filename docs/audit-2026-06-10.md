# Design Audit — 2026-06-10

**Method:** 191 agents in five waves — 14 extractors (sonnet) over all 32 docs, contract reconcilers (sonnet) verdicting every cross-doc claim, 10 walkers (opus: 5 concrete scenario traces + 5 invariant sweeps), 4 gap lenses (opus), then severity-tiered adversarial verification (blockers/design-bugs: 2 opus refuters; others: 1 sonnet refuter, default-to-refute). **226 raw findings → 128 verified → 26 confirmed, 1 contested, 101 killed.** The 79% kill rate is the quality signal: what survived was attacked and stood. Full machine output: workflow `wf_59cd8929-345` (498KB JSON, session task `wwlzjs6cn`). 98 unverified nits retained there; none repeated below unless independently confirmed.

## Headline verdicts

1. **The four load-bearing invariants HOLD across all 33 documents.** Compute/generate split: clean (the LLM never computes a value or holds an invariant anywhere in the design). Vault wall: clean (no mechanism leaks ground truth or another mind). One-way arrows: clean (nothing writes prose back to state). Director-never-forces: clean in every vector checked — envelope, authored-backward principals, cutting room, urge-scheduler pinning — **except one seam** (finding 2 below).
2. **The per-doc logic is mostly sound; the SEAMS are not.** All five scenario walks (generation, sim turn, debate, world consequence, the cut) found hop mismatches — places where a doc consumes an artifact its upstream never produces.
3. **Three design sections are genuinely missing** (the answer to "did we miss a section"): the **measurement/judge layer**, the **voice/prose-style layer**, and **run lifecycle**. Detail in §C.

## A. The blocker

**A1. The EDL flashback anchor consumes an artifact that is never produced.** `cutting-room.md` anchors real-time-POV flashbacks to `recall_event_id` — but recall is an engine *input* to a turn (relevancy-gate injects it), never a recorded *output*; the typed event vocabulary has no recall/remember type; and only principal-depth characters get thought capture at all. The contract is written against a nonexistent record. *(Walk: the-cut. Verified 2-0 opus.)*
**Fix direction:** either consolidation logs salient recalls as events (the gate already computes which beliefs were injected — cheap write), or the recall-anchor rule is dropped and nonlinearity is licensed only for retrospective narrators. Decide in the room.

**This generalizes — the audit's strongest theme: the record is thinner than its consumers assume.**
- **A2.** The consequence graph's read-side edge ("the later decisions that read that state") is persisted nowhere — event→state writes are recorded, but state→decision consumption is not, so the cut's "causality as a DB join" is missing one of its two join keys. *(Confirmed.)*
- **A3.** `cutting-room.md` claims `relationships.md` stores relationship-edge deltas "queryable as significant moments" — it doesn't (it defines the update rule, not a queryable moment log). *(Confirmed broken claim.)*
**Fix direction (one move):** a **record-contract section** — the cutting room's read-requirements become the recording layer's write-requirements: per-turn decision-input logging, relationship-delta events, recall events. One short doc or a section in `recording-model.md`.

## B. Confirmed design bugs & inconsistencies

**B1. Director-set DC is a fiat path into a character's mind.** `relevancy-gate.md`'s check-resolution option lets the director set a check *outcome* (recognize the sigil / notice the lie) — cognition by decree, violating the invariant the rest of the design enforces everywhere. The same doc already contains the compliant route (deplete the character via staged circumstance). The doc marks the fork "Unresolved — the author's call." The audit's input to that call: the fiat option is the only invariant violation in 33 docs. *(Invariant sweep + 2-0 opus.)*

**B2. The keystone hop is specified two incompatible ways.** `consolidation-loop.md`: the character-turn LLM *emits* event-tags; consolidation *mechanically validates*. `design.md` (older): consolidation is an LLM call that *extracts* events by interpreting prose. Different output contract, different failure surface, for the single highest-risk mechanism. Consolidation-loop is the newer, deliberate design — `design.md` LLM-call #3 needs rewriting to match. *(Confirmed.)*

**B3. `character-schema.md` contradicts itself on CURRENT's writer** — "written every turn by appraisal + decay" two lines above "the consolidation loop is the only writer of `current`." Resolution is known (events arrive via consolidation; appraisal/decay are the engine's computation of the write) — the prose just has to say it. *(Confirmed, lines 48–49.)*

**B4. Future-dated events need two clocks; the ledger gives them one.** `world-dynamics.md` requires caused-at + effective-at; the ledger tuple carries a single `when`. Trivial schema fix, real hole. *(Confirmed.)*

**B5. Cross-claim breaks (each a one-line repair or a real small design):** scene-assembly reuses the gate's (trigger, skill, DC) machinery "against the scene" — a mode `relevancy-gate.md` never defines (B5a). `multi-character.md` calls its debate verbs (assert/rebut/concede…) "the consolidation event schema" — disjoint from the actual harm/aid/betray vocabulary (B5b). `world-dynamics.md` cites design.md's "write-path #3" for placed-circumstance canonicalization — the actual text doesn't say it (the *ledger* doc does; fix the pointer) (B5c). `character-anatomy.md`/`character-model.md` attribute voice mechanics to `narration.md`, which defines POV boundaries, not voice (B5d → feeds C2).

**B6. Undefined formula operands in the arc engine.** `Magnitude = appraised-impact × durability × (1 − resilience)` — neither **durability** nor **resilience** is defined, stored, or derivable from any schema field; baseline-generation's six genetic axes yield neither. The docs' own open-questions concede it. Not mere calibration: the formula references state that doesn't exist. *(Both 2-0 opus.)*

**B7. Two rules stated as hard are currently unenforceable:** "no record enters state on low-confidence extraction" (confidence scoring is itself open-Q 2); `goal.status: blocked` has no transition logic (who sets it, what it does to priority). *(Both confirmed.)*

**B8 (contested, 1-1 opus split):** scene-assembly lists Layer-7 state in both the stable prefix and the volatile body. Worth one careful read in the room; the split vote means the text is at least ambiguous.

## C. Missing design sections (the "did we miss anything" answer)

**C1. The measurement/judge layer — the most consequential gap.** The coherence probe's two primary pass-conditions ("state stays sane", "recognizably the same person") have **no operational definition, threshold, or detector anywhere**; the consistency critic (pipeline layer 6) is named, called the highest-risk piece by the design itself, and never designed; the cut probe's shape/distinctness judgments have no rubric or protocol. The de-risk sequence is gated on a measurement regime that doesn't exist — and it sits *beyond* the known-pending list (calibration + content). *(Three findings, all confirmed.)*

**C2. The voice/prose-style layer.** Acceptance criterion #2's "blind voice-attribution beats chance" has a schema slot but **no generation path** (baseline-generation, "where every per-character number is born," never produces a voice profile); criterion #6's quality bar — "voice rules, structural lessons, the **An Axle standard**" — exists **nowhere in the 32 docs** (grep-proven: the only hit is the criterion naming it). The standards live in the writers-desk world; the design must import or pointer them, and something must *generate* voice. *(Three findings confirmed.)*

**C3. Run lifecycle.** No save/resume, crash recovery, or idempotent-retry design for runs whose stated horizon is hundreds of turns — while the project's own prior-art catalog documents API instability as a verified failure mode. The event-sourced ledger makes resume *possible in principle*; no doc says the run uses it that way. *(Confirmed.)*

**C4. Salami forcing is owned by no one.** The forcing audit checks each director choice against the envelope *it was made under*; nothing audits a **sequence** of individually-plausible circumstances that together corner a character toward an outcome the books would forbid in a single move. A failure mode of our own architecture, found by the fresh-lens pass, survived refutation. *(Confirmed.)*

## D. What was attacked and held (worth knowing)

101 findings died under refutation — among them: most claimed contradictions in the character-layer stack (schema/anatomy/model numbering disputes), the determinism complaints (refuters found the design's stated answers sufficient), scene-sequencing/character-death/cost-governor "missing sections" (refuters located owners), and 17 of the cross-claim breaks (the docs actually do support them). The design is substantially more internally consistent than the raw finding count suggested — the verification layer is why this report is short.
