# PLAY — the band set

**Status: DRAFT, for review.** Twenty bands at 0.05 steps. Rules as `docs/phrases-seeking.md`.

**The variable: how much of what you are doing has no purpose beyond doing it.**

**The competing axis this set must NOT encode:** **pleasure.** The first draft of the regions drifted onto an enjoyment axis (*amusement, delight*). Purposelessness and enjoyment correlate and are not the same; this scale is the first.

Regions (`docs/emotion-scales.md`): earnest / levity / play / absorption / flow

| band | phrase |
|---|---|
| 0.00 | everything you are doing is for something else |
| 0.05 | nothing you are doing is for its own sake, and it has not occurred to you that anything could be |
| 0.10 | you would not spend a minute on something that went nowhere |
| 0.15 | what is funny registers, and you do not follow it |
| 0.20 | you let a joke through and do not chase it |
| 0.25 | you spent a moment on something that was not going anywhere |
| 0.30 | you are taking the longer way through this, and not because it gets you anything |
| 0.35 | you have stopped counting whether this is worth the time |
| 0.40 | the useful part of this is nearly done and you are not slowing |
| 0.45 | the useful part finished a while ago |
| 0.50 | you are doing the thing rather than getting it done |
| 0.55 | you are past the point of usefulness and have not stopped |
| 0.60 | what this is for has become hard to state |
| 0.65 | how long you have been at this is not a question you have asked |
| 0.70 | you would have to reconstruct why you started |
| 0.75 | what this was for has stopped sounding like a real question |
| 0.80 | the purpose has gone and you did not notice it go |
| 0.85 | what is outside this has stopped asking you to keep track of it |
| 0.90 | you have lost the thread that ties this to anything else |
| 0.95 | this is its own reason now, and any stake would have to reach in from outside it |

## Notes

* The ceiling is Csikszentmihalyi's **flow** — absorption, loss of self-consciousness, the activity
  becoming its own reward. That last clause is this primitive's definition, so the referent is not
  a coincidence of naming.
* PLAY is the only primitive with a complete negative half in `state._DIM_TO_PRIMARY` (threat,
  loss and social_violation all lower it), and the only one that fell correctly in the measured
  slave case. It is the worked example the other seven should look like.
