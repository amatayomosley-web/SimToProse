# Acceptance Criteria — "a finished book"

Work backward from this. The finished product is **one complete novel**, one world, 3–7 major characters, one central conflict, that passes these **observable** tests:

1. **Continuity** — a full-book audit finds **zero** contradictions with the world bible or the book's own earlier events.
2. **Character integrity** — every major action traces to a stated goal/value/flaw; blind voice-attribution beats chance (a reader can tell who's speaking).
3. **Dramatic shape** — every planted setup pays off; tension escalates to a climax; a test reader calls it **"a story,"** not "it meanders."
4. **Grounded, not set-dressing** — core world-rules (a law, the economy, the religion) are **load-bearing to the climax**: remove one and the ending breaks.
5. **Reads as prose** — POV, interiority, scene-craft — not a stage-direction log.
6. **Quality bar = the author's codified craft standards** (voice rules, structural lessons, the "An Axle" standard) — these instantiate #2, #3, #5.

If the output hits these, it worked. If not, the failing criterion names the component to fix.

## Two gates before any full build
- **Know what it is** — world seed + central question + theme + ending (creative inputs) and these criteria. *(Mostly defined; needs the story seed.)*
- **Know it will work** — the probe in `probe-plan.md` passes. *(Cannot be settled by design alone — only by the test.)*
